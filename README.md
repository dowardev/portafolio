# Porfolio Backend

Backend para la aplicación del <a href="https://gitlab.com/gonzam4/portafolio" target="_blank">porfolio</a>

## Despliegue en local

- Tener instalado php, composer y Mysql
- Clonar proyecto.
  `https://gitlab.com/gonzam4/portafolio-backend.git`
- Acceder con nuestra terminal de comandos a la ubicación del proyecto y ejecutar.
  `composer install`
- Realizamos las migraciones
  `php artisan migrate`
- Iniciamos el servidor
  `php artisan serve`

### Nota
